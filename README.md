# Zipper — Three Design Versions

Static client-review website and interactive sample dashboards.

- index.html: comparison homepage
- clean.html / clean-dashboard.html: Clean & Minimal
- dark.html / dark-dashboard.html: Dark & Premium
- corporate.html / corporate-dashboard.html: Bold & Corporate

Open index.html locally or publish the main branch root with GitHub Pages.
No dependencies or build step. All images, styles and scripts are included.

This is an interactive frontend demonstration. Sample records and browser-local
forms are not connected to real login, live payments, email, refunds, crypto
processing or the existing client API. No credentials or private client data
are included. Commission calculations and operational records are illustrative.
